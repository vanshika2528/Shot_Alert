# ShotAlert

ShotAlert is a real-time alert system designed to detect critical incidents like gunshots or loud noises and notify nearby users and authorities instantly. The app improves public safety through sound detection, GPS tracking, and fast communication.

---

## 🚀 Features

- 🔊 **Gunshot & Loud Noise Detection**
- 📍 **Real-Time Location Tracking**
- ⚠️ **Instant Notifications**
- 🗺️ **Live Incident Map**
- 📱 **Cross-Platform Support (Android/iOS)**
- 🛡️ **Privacy-Preserving Sound Processing**

---

## 🛠️ Tech Stack

- **Frontend:** Flutter / React Native
- **Backend:** Firebase / Node.js / Flask
- **Database:** Firebase Firestore 
- **ML Integration:** TensorFlow Lite 
- **Map APIs:** Google Maps API / Mapbox
